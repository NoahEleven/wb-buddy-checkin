# 坐标校准指南（wb-buddy-checkin）

脚本用「相对客户区左下角」的三个常量来定位点击点。这套设计让窗口任意缩放都命中，
但**每个人的屏幕分辨率 / WorkBuddy 窗口布局不同，首次使用必须校准**。

## 三个常量

| 常量 | 含义 | 默认示例值 |
|---|---|---|
| `AVATAR_LEFT` / `AVATAR_BOTTOM` | 左下角头像（账户菜单）距客户区左 / 底边缘 | 94 / 41 |
| `GAS_LEFT` / `GAS_BOTTOM` | 「Buddy 加油站」菜单项距左 / 底边缘 | 140 / 541 |
| `CLAIM_LEFT` / `CLAIM_BOTTOM` | 「立即领取」按钮距左 / 底边缘 | 89 / 113 |

> 客户区 = 窗口去掉标题栏和边框的内部区域。坐标用逻辑像素（脚本会自动乘 DPI 缩放）。
> 默认值是**作者屏幕的校准值**，只是占位示例——别人必须用下面的方法重新校准，否则会"只点头像"。

---

## ✅ 方法一：弹窗校准（首选，通用、零依赖、最傻瓜）

不需要截图、不需要终端交互、不需要任何外部通道——脚本弹出一个**右上角半透明悬浮窗**，
显示当前步骤、实时鼠标坐标和倒计时，每步倒计时结束**自动采样**你鼠标的位置，三步写 `calibrate.json`。

```bash
python scripts/wb_mouse_checkin.py -calibrate-gui
```

弹窗出现后，按提示分三步（窗口在右上角，不会挡住左下角的头像和中间的菜单）：

1. **头像**：把鼠标移到左下角【头像】→ 保持不动，倒计时（6秒）结束自动记录。
2. **Buddy 加油站**：点击头像展开菜单，把鼠标移到菜单里的【Buddy 加油站】项 → 保持不动，自动记录。
3. **立即领取**：点击加油站打开积分面板，把鼠标移到【立即领取】按钮 → 保持不动，自动记录。

脚本自动把三个真实屏幕坐标换算成「相对客户区左下角」并保存到 `calibrate.json`。
**之后每次 `-run` 都会自动读取该文件覆盖默认坐标**，无需再改代码。

> 依赖 Python 标准库 `tkinter`（绝大多数 Windows Python 自带）。若你的环境没有 tkinter，
> 脚本会提示改用下面的「方法二：终端校准」。

---

## ✅ 方法二：终端校准（无 GUI 时备用，零测量误差）

不需要截图和画图量像素，脚本读取你鼠标的真实位置。需开终端、手动按回车：

```bash
python scripts/wb_mouse_checkin.py -calibrate
```

按提示分三步操作（每步把 WorkBuddy 置前，鼠标移到目标点后，切回终端按回车）：

1. **头像**：让账户菜单收起，鼠标移到左下角头像 → 回车。
2. **Buddy 加油站**：点开头像菜单，鼠标移到菜单里的「Buddy 加油站」项 → 回车。
3. **立即领取**：点开「Buddy 加油站」面板，鼠标移到「立即领取」按钮 → 回车。

脚本自动把三个真实屏幕坐标换算成「相对客户区左下角」并保存到 `calibrate.json`。
**之后每次 `-run` 都会自动读取该文件覆盖默认坐标**，无需再改代码。

> 校准中途想放弃按 `Ctrl+C` 即可，没存盘不会破坏原有校准。

---

## 方法三：直接改代码常量（不推荐，仅核对用）

适合无法手动操作鼠标的自动化环境，或想核对坐标时：

1. 手动打开 WorkBuddy，点击左下角头像展开菜单，让「Buddy 加油站」面板可见。
2. 用系统「画图」打开一张窗口截图：
   - 「立即领取」按钮中心：距图片**左边缘**像素 = `CLAIM_LEFT`；距图片**底边缘** = `CLAIM_BOTTOM`。
   - 同理量头像（`AVATAR_*`）和「Buddy 加油站」项（`GAS_*`）。
3. 把值填进 `scripts/wb_mouse_checkin.py` 顶部配置区，保存。

---

## 验证

校准完成后跑真实签到：

```bash
python scripts/wb_mouse_checkin.py -run
```

- `结论: SUCCESS` 且截图按钮变灰「今日已领」= 校准正确。
- 报失败并提示 `请重新校准 GAS_*` → 加油站菜单项没点中（面板没开）。
- 报失败并提示 `请重新校准 CLAIM_*` → 面板开了但领取按钮没点中。
- 报"坐标落在窗口之外" → 某个常量填反了（距左/距底搞混），重测。

## 常见问题

- **只会点头像 / 后续点击打空**：没校准，用的是默认示例坐标。先 `-calibrate` 交互记录三个点。
- **点击打空 / 窗口没被置前**：Win32 调用未声明 `argtypes` 导致 HWND 被截断的典型症状，本脚本已修复（所有 `user32`/`gdi32`/`kernel32` 调用都显式声明签名）。若仍无效，确认 WorkBuddy 未被最小化到托盘且未被其他全屏窗口遮挡。
- **暗色主题误判**：校验用「近黑像素数」而非白字数（灰底「今日已领」也含白字），主题无关，亮/暗色都正确。
- **截图失败**：优先用 desktop-control-win 的 `screen-info.ps1`；若未安装该 skill，自动回退到 `PrintWindow` 客户区截图。两者都失败则签到仍会执行但无法自动校验（退出码 2）。
